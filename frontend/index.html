🧠 How the Models Work

A brief explanation for academic understanding.

📈 Linear Regression

Used to predict a continuous numerical value — your expected Marks. It fits a straight-line relationship between the input features (hours, attendance, previous marks) and the output (score). Evaluated using MAE, MSE, and R².

✅ Logistic Regression

Used to predict a categorical outcome — Pass or Fail (1 or 0). It estimates the probability of passing using the sigmoid function. Evaluated using Accuracy, Precision, Recall, and Confusion Matrix.

🔢 Features Used

Hours: Daily study hours
Attendance: % of classes attended
Previous Marks: Marks in prior exam
All three strongly correlate with academic performance.
